Container Simulator

See what each Docker and Compose command from COMPSCI 426 does, change it, and run it again. This is a teaching model of the commands the course uses, not Docker itself: each activity ends with the same task on your own machine.

Your work is saved in this browser on this computer only. Clearing the browser, a private window or another computer starts empty: export your work to keep a copy, and import it to carry on elsewhere. The exported file is what you submit in Canvas.
