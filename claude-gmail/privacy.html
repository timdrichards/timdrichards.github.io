claude-gmail

Privacy Policy

How claude-gmail handles Gmail data. Last updated October 22, 2026.

Who uses it

claude-gmail is a personal tool. Its only user is me, Tim Richards, on my own Gmail accounts. It is not available to the public.

What it accesses

With my permission, given through Google sign-in, the tool uses the Gmail scope gmail.modify. That lets it read messages and labels, change labels (including archiving and marking read), move messages to Trash, and create and send drafts. It cannot delete mail permanently.

How the data is used

The tool uses Gmail data only to show me my own mail and to carry out the actions I ask for. What it reads is shown in my own Claude Code sessions on my Mac, where Claude, Anthropic's AI assistant, helps me decide what to keep, archive or delete and helps me draft replies. Mail is not used for advertising, is not sold, and is not shared with anyone else.

Where it is stored

The tool keeps no copy of my mail. The Google sign-in tokens are stored only on my own computer, in a folder that only my user account can read. There is no server and no database.

Google API Services User Data Policy

claude-gmail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from the Google Account page under Third-party apps and services, or by deleting the tokens from my computer.

Contact

Questions about this policy go to Tim Richards at tim.d.richards@gmail.com.
