A personal tool

claude-gmail

A small command-line tool I wrote to sort my own Gmail with the help of Claude, Anthropic's AI assistant.

What it does

claude-gmail runs on my own Mac. It reads my two Gmail inboxes (my university account and my personal account) through the Gmail API so I can list messages, read them, archive them, move them to Trash, add and remove labels, and write drafts. It sends a draft only after I have read it and asked for it to be sent.

It is for my own accounts only. It is not offered to anyone else, there is no sign-up, and nobody else can use it with their mail.
